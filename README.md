# THE WATCHERS

A cooperative gothic horror demo built with Decentraland SDK 7. Search the chapel for red crystals, keep your candle lit at igniters, avoid Watchers and ghosts, and return 25 crystals to the altar to open the escape gate.

This is a **test scene**, not the finished game. The [Game Design Document](design/gdd.md) describes the current loop, social play, replay goals, and planned updates.

## Test scene

Play the published test scene in [raccooncity.dcl.eth](https://decentraland.org/play/?realm=raccooncity.dcl.eth), or use `decentraland://?realm=raccooncity.dcl.eth&dclenv=org` in the Decentraland desktop app.

## Local preview

Run `npm install` and `npm run start` in the project directory. Use the Decentraland client or the Creator Hub preview. Desktop: WASD to move, mouse to look, Space to jump, and E to interact. Mobile: joystick, drag to look, jump control, and E interaction control.

## Status

The demo includes the chapel and grounds, crystals, igniters, Watchers, ghosts, the caretaker, a briefing, capture and retry flow, and score UI. Multiplayer persistence and mobile gameplay need a final live World test after deployment. Planned features are labeled separately in the GDD.
